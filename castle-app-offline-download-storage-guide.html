캐슬앱 오프라인 동영상 저장 기능 및 외장 SD카드 용량 관리 가이드

장거리 해외여행 비행기 안이나 지하철 음영 지역, 혹은 데이터 요금제가 제한적인 환경에서는 오프라인 저장 기능이 최고의 해결책이 됩니다. 캐슬앱의 멀티스레드 다운로드 매니저를 활용해 원하는 작품을 빠르게 보관하고 저장 공간을 체계적으로 관리하는 방법을 소개합니다.

목차 (빠른 이동)
  1. 영화 및 시리즈 에피소드 일괄 다운로드 사용 방법
  2. 백그라운드 다운로드 끊김 방지(배터리 최적화 예외 처리)
  3. 내부 저장소 부족 해결 및 외장 SD카드 경로 변경
  4. 임시 스트리밍 캐시와 오프라인 보관 파일 구분 정리하기

영화 및 시리즈 에피소드 일괄 다운로드 사용 방법

원하는 영화나 드라마 상세 정보 페이지에 접속하면 재생 버튼 아래에 다운로드(화살표) 아이콘이 배치되어 있습니다. 단편 영화의 경우 아이콘을 누르면 즉시 480p, 720p, 1080p 중 원하는 저장 화질과 예상 파일 용량이 표시되며, 시즌제 시리즈물의 경우 1화부터 최종화까지 체크박스로 여러 편을 한 번에 선택하여 대기열(Queue)에 등록할 수 있습니다.

다운로드 작업이 시작되면 하단 내 보관함의 다운로드 관리 탭에서 실시간 전송 속도와 남은 시간을 직관적으로 확인할 수 있습니다. 앱 내 다운로드 설정에서 동시 다운로드 작업 수를 2개 또는 3개로 지정하면 대역폭을 안정적으로 배분하여 개별 파일의 완료 속도를 높일 수 있습니다.

백그라운드 다운로드 끊김 방지(배터리 최적화 예외 처리)

여러 편의 고화질 영상을 걸어두고 화면을 끈 채 잠시 다른 일을 하다 돌아왔을 때 다운로드가 일시 정지되어 있다면, 안드로이드 운영체제의 절전 정책이 백그라운드 네트워크 프로세스를 강제로 절전 상태로 전환했기 때문입니다.

이를 완벽히 해결하려면 스마트폰 설정 → 애플리케이션 → 캐슬앱 → 배터리 항목으로 이동하여 배터리 사용량 옵션을 제한 없음(Unrestricted)으로 변경해 주어야 합니다. 또한 와이파이 고급 설정에서 절전 모드 중 Wi-Fi 연결 유지 옵션이 항상 켜짐으로 되어 있는지 확인하면 화면이 꺼진 심야 시간에도 수 기가바이트 분량의 시즌 전체 패키지를 끊김 없이 내려받을 수 있습니다.

  • Wi-Fi 전용 다운로드 잠금: 작업 도중 와이파이가 끊겨도 모바일 데이터로 자동 전환되지 않도록 안전장치 활성화
  • 시청 완료 후 자동 삭제 옵션: 감상을 마친 에피소드를 48시간 뒤 정리하여 여유 공간 자동 확보
  • 자막 트랙 동시 패키징: 오프라인 상태에서도 한글 자막이 함께 표시되도록 다운로드 시 자막 언어 포함 확인
  • 손상 세그먼트 이어받기: 네트워크 일시 단절 시 처음부터 다시 받지 않고 중단 지점부터 재개 지원

내부 저장소 부족 해결 및 외장 SD카드 경로 변경

태블릿이나 마이크로SD 슬롯을 지원하는 스마트폰을 사용 중이라면 대용량 미디어 파일은 기본 내부 메모리 대신 외장 SD카드로 저장 위치를 변경하는 것이 기기 속도 유지에 유리합니다. 앱 설정의 다운로드 저장 경로(Storage Location) 항목을 탭하면 현재 내부 저장소와 외장 메모리의 잔여 기가바이트 용량 그래프가 나란히 표시됩니다.

외장 SD카드를 선택할 때는 쓰기 속도가 안정적인 UHS-I U3 또는 V30 등급 이상의 정품 메모리카드를 사용하는 것이 좋습니다. 저속 구형 메모리카드를 사용할 경우 고속 다운로드 도중 디스크 쓰기 병목 현상이 일어나거나 고비트레이트 구간 탐색(빨리 감기) 시 미세한 지연이 발생할 수 있기 때문입니다.

임시 스트리밍 캐시와 오프라인 보관 파일 구분 정리하기

많은 사용자가 앱 용량을 줄이기 위해 안드로이드 시스템 설정에서 무심코 데이터 삭제 버튼을 누르곤 하는데, 이 경우 정성껏 내려받은 오프라인 영상 목록과 개인 맞춤 설정까지 모두 초기화되므로 주의가 필요합니다.

오프라인 보관함의 소중한 영상은 그대로 보존하면서 불필요한 포스터 썸네일과 임시 스트리밍 찌꺼기만 비우고 싶다면 반드시 캐슬앱 내부 설정 메뉴에 마련된 캐시 지우기(Clear Cache) 기능만 실행하거나 시스템 앱 정보에서 데이터 삭제가 아닌 캐시 삭제 버튼만 선택하시기 바랍니다.
